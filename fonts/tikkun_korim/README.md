# חלופות וי״ו קטיעא

שלושת גופני Culmus המשמשים בתיקון קוראים — אשכנזי, ספרדי וכתר
(חלופה לטור המנוקד) — כוללים את החלופות הבאות. אותו מיפוי נוסף במקורות
של שתי משפחות אוצריא אשורית, בשני המשקלים, במאגר
[otzaria-ashurit](https://github.com/palmoni5/otzaria-ashurit).

| קוד פרטי | סיומת שם הגליף `vav.ketia.` | צורה |
|---|---|---|
| U+E140 | small | וי״ו זעירא — כל האות קטנה |
| U+E141 | yod | כעין יו״ד, מתוך צורת היו״ד של הגופן |
| U+E142 | short | ראש בגודל הרגיל ורגל קצרה |
| U+E143 | split | הפסק ישר ברגל |
| U+E144 | splitDiagonal | הפסק אלכסוני ברגל |
| U+E145 | splitHigh | הפסק גבוה, חלק עליון קצר |
| U+E146 | shortTail | רגל קצרה והמשך קטן נפרד למטה |
| U+E147 | smallTail | וי״ו זעירא והמשך קטן נפרד למטה |
| U+E148 | bridge | קטיעה ישרה עם חיבור בחוט דק |
| U+E149 | bridgeDiagonal | קטיעה אלכסונית עם חיבור בחוט דק |
| U+E14A | insetDiagonal | חריץ אלכסוני פנימי, מסגרת הרגל נשארת מחוברת |

וי״ו רגילה נשארת U+05D5. בתיקון קוראים ברירת המחדל היא וי״ו רגילה בתימן,
ורגל קצרה והמשך נפרד (U+E146) באשכנז ובספרד. ניתן לבחור ידנית בכל החלופות
בהגדרות הכלי ובהגדרות הכלליות. ההחלפה נעשית רק בעת הרינדור של ״שלום״
בבמדבר כה, יב, בשני הטורים ובייצוא ל־PDF; שכבת ההעתקה והחיפוש נשארת עברית.
בגופן שאינו כולל את החלופות מוצגת וי״ו רגילה.
הקודים פרטיים ואינם תווי Unicode תקניים לווי״ו קטיעא. לכל החלופות אותו
מהלך אופקי כמו לווי״ו הרגילה, והן יורשות את עוגני הניקוד שלה.

הצורות מבוססות על המקורות שנאספו ב[חבל נחלתו יח, כו](https://he.wikisource.org/wiki/חבל_נחלתו_יח_כו):
רבנו בחיי ומסורת אותיות זעירות; פירושי צורת יו״ד; מנחת שי והרגל המקוצרת;
ריטב״א ואור תורה והאות המופסקת; רדב״ז ח״ח קפא והחיבור בחוט דק;
רעק״א קמא עה וערוך השולחן יו״ד רעה:כב וההמשך הנפרד.
החלופות האלכסוניות וההפסק הגבוה הן צורות משנה המתוארות בדיון.

## שחזור ובדיקות

```sh
python -m pip install fonttools==4.65.0 skia-pathops==0.9.2 uharfbuzz==0.56.1
python tool/tikkun_korim/prepare_vav_ketia.py
python tool/tikkun_korim/test_vav_ketia.py
```

הארגומנט `--ashurit-source <repository>` מעדכן גם את מקורות ה־UFO וטבלאות
הניקוד של מאגר אוצריא אשורית. בניית קובצי ה־OTF נעשית בכלים שלו, ורק לאחר
מכן ניתן לבדוק גם אותם:

```sh
python tool/tikkun_korim/test_vav_ketia.py --ashurit-fonts <repository>/out
```

בדיקות הגופנים משוות את המתארים והמידות של כל הגליפים המקוריים לחתימות
שלפני ההרחבה, ומוודאות כיסוי, רוחב, הבדל בין צורה מופסקת למחוברת ומיקום
ניקוד וטעמים במילה. קובצי Culmus וההרחבות בהם נשארים תחת GPL-2.0 עם
חריג הטמעת הגופנים המקורי; הודעות היוצרים והרישיון שבקבצים נשמרות.
